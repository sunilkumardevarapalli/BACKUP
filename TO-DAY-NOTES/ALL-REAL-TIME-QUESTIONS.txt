1. What is React?
Answer:
React is a JavaScript library developed by Facebook for building user interfaces, particularly single-page applications. It allows developers to create reusable UI components and manage dynamic data changes efficiently using a virtual DOM.
🔹 2. What are the key features of React?
Answer:
JSX – JavaScript syntax extension that looks like HTML
Components – Independent, reusable pieces of UI
Virtual DOM – Efficient rendering by diffing changes
Unidirectional Data Flow – Data flows from parent to child
Hooks – Functions for using state and lifecycle in functional components
🔹 3. What is JSX?
Answer:
JSX stands for JavaScript XML. It allows you to write HTML elements in JavaScript. JSX is then transpiled to React.createElement() calls by Babel.
jsxCopyEditconst element = <h1>Hello, World!</h1>;
🔹 4. What is the difference between functional and class components?
Feature	Functional Component	Class Component
Syntax	JavaScript function	ES6 class
State Management	Uses useState, useEffect	Uses this.state, lifecycle methods
Simpler to write	✅	❌
 
🔹 5. What are props in React?
Answer:
Props are read-only inputs passed from parent to child components to pass data or callbacks.
jsxCopyEditfunction Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
🔹 6. What is state in React?
Answer:
State is a mutable object used to track changes in a component. Updating state causes the component to re-render.
jsxCopyEditconst [count, setCount] = useState(0);
🔹 7. What are React hooks?
Answer:
Hooks are functions introduced in React 16.8 that let you use state and other features in functional components.
Common hooks:
useState – manage state
useEffect – handle side effects (e.g. API calls)
useContext – access context API
useMemo, useCallback – performance optimizations
🔹 8. What is the Virtual DOM?
Answer:
The Virtual DOM is an in-memory representation of the real DOM. React updates the virtual DOM first, compares it with the previous version (diffing), and applies only the necessary changes to the real DOM (reconciliation), improving performance.
🔹 9. What is conditional rendering in React?
Answer:
Render elements/components conditionally using:
if statements
Ternary operator
Logical &&
jsxCopyEdit{isLoggedIn ? <Logout /> : <Login />}
🔹 10. What is useEffect used for?
Answer:
useEffect handles side effects in functional components (e.g., fetching data, subscriptions, manually updating the DOM).
jsxCopyEdituseEffect(() => {
  // side effect logic here}, [dependencyArray]);
🔹 11. What is lifting state up in React?
Answer:
When multiple components need to share state, you lift the state up to their common parent component, and pass it down via props.
🔹 12. What are controlled and uncontrolled components?
Feature	Controlled Component	Uncontrolled Component
Data source	React state	DOM (via refs)
Control	React controls the input	Browser handles it
 
🔹 13. What is React Router?
Answer:
React Router is a library for handling routing in React apps. It allows you to define multiple pages/views and navigate between them.
jsxCopyEdit<BrowserRouter>
  <Route path="/about" component={About} />
</BrowserRouter>
🔹 14. What is Redux in React?
Answer:
Redux is a state management library that provides a centralized store for the entire application. It follows a unidirectional data flow with actions, reducers, and store.
🔹 15. How can you optimize performance in a React app?
Answer:
Use React.memo() to prevent unnecessary renders
Use useMemo() and useCallback() to memoize functions and values
Split code using React.lazy() and Suspense
Avoid unnecessary state and props
