# Important Interview Notes

### ✅ ArrayList

* Best for **reads**, random access, and appending.
* Middle insert/delete is **O(n)** due to element shifting.

### ✅ HashMap

* Best general-purpose collection for **CRUD** (Create, Read, Update, Delete) using keys.
* Average **O(1)** for put, get, remove.

### ✅ ConcurrentHashMap

* Best for **multi-threaded** key-value storage.
* Highly scalable with minimal contention.

### ✅ CopyOnWriteArrayList

* Excellent for **read-heavy** concurrent applications.
* **Avoid** if writes are frequent because every write copies the entire array.

### ✅ LinkedList

* Rarely the best choice in modern Java.
* Useful mainly when:

  * Frequent insert/delete at a known node.
  * Implementing a deque (though **ArrayDeque** is usually faster).

### ✅ ArrayDeque

* Preferred over **LinkedList** for queue and stack implementations.
* Better cache locality and lower memory overhead.
